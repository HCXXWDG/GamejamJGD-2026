# 肌肉与拮抗动作

第二关和第三关现在提供更多骨头、肌肉及全部关节形状。第一关仍用于核心滚动教学。

在同一圆形关节或核心的两侧连接骨头后，可以在两块骨头的内侧和外侧分别安装肌肉，绑定不同的 WASD 键。新放置时保留玩家点击的骨头内部位置；点击哪一侧就选择哪一侧的牵引路线。中心线附近只作小幅侧向偏移，避免将附着点推到细骨头外面的碰撞矩形边缘。

肌肉接近圆形关节时，通过切线和圆弧绕过关节，转动后保持原来的绕行侧。骨骼伸直时仍有力臂，两个方向可以分别牵动。界面预览、游戏显示和物理收缩使用同一路径。

存在一对拮抗肌时，两侧松键后的被动刚度与最大回弹力为原来的 30%；按住一侧的键时，对侧未按键肌肉进一步降为 10%，给主动牵引让出空间。阻尼按减弱后的刚度调整，使恢复较平缓。主动收缩和单侧肌肉的力度保留；同时按住两侧时，两条肌肉均主动收缩，可形成更硬的支撑。

重新组装或重新摆放肌肉会按新的摆放姿势选择路线。关节断开后，肌肉解除该处绕行，以当下的直线长度重新建立基准，避免释放旧绕行路径的储能。已有肌肉的附着坐标不会被自动改写。

程序实现位于 `AssemblyMuscleRouting`、`AssemblyMuscle` 和 `JGDAssemblyPhysicsExecutorComponent`。GameplayTags 输入消息维持原接口。
